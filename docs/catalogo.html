Entre para ver o catálogo

O acervo das lâminas é restrito. Entre com a sua conta Google para consultá-lo.

Avaliação cega. Para não influenciar os citopatologistas que ainda vão avaliar, esta página não mostra classificações, descrições nem avaliadores: só a imagem, o ID, a data e quantas avaliações cada lâmina já recebeu. O quórum oficial exige a concordância de pelo menos 3 citopatologistas. Para cadastrar lâminas e avaliar, use o CitoAtlas ou o aplicativo (modo profissional).

Sobre este acervo
